# ADR-002：世界线、批处理与吸附语义

- **状态**：accepted（2026-09-18 拍板）
- **日期**：2026-09-18
- **来源**：20260830 定位会话精读（Pair 8/12/15/18/20）回写至《设计：场景工坊》第十二章

## 一、背景

SK 已具备 WorldSnapshot/WorldDelta 列式协议、ModelCommand 命令队列与 tick 边界校验；SA 具备录像带式时间线（环形帧缓冲）。产品定位要求"沙盘推演"能力：分支对比、批量操作、规则验证吸附。本 ADR 锁定这四组语义的层次归属与接口口径，防止后续实现散落走样。

## 二、决策

### D1 世界线 = 快照存档的 DAG（SK 运行时 + 上层存档库）

- **节点** =（snapshotId, tick）处的完整快照；**边** = 演化区间（tick 段 + 命令流）；fork = 从任意节点新建 ModelSession 并以该快照为初始态。
- **merge**：合理合并 = 两侧快照列合并 + 冲突检测（同 (kind,uid) 列值不等记冲突项，交由上层裁决）；强制合并 = 跳过冲突检测的并集，冲突边仅标记。
- **A/B 快照对比** 降级为世界线视图的内建特例，不再作为独立功能立项。
- 存档形态：`WorldSnapshot` JSON/msgpack 文件即世界线节点的通用 interchange；SK 核心只提供 `from_snapshot()` 水合入口，树结构（父子、标签、注释）归 SA/中游的存档库层。
- 与 ES 符号仿真"每集重置、无分支"决策不冲突：那是实验管理层的用法，本 ADR 只定运行时能力。

### D2 交互式批处理 = SelectionSet + 命令扇出（SK 语义，SA UI）

- SK 新增选择集原语：`select(kind, ids) / clear_selection()`，选择集是会话态、不进快照。
- 批处理宏 = 单条 `ModelCommand`（如 `batch_move / batch_set_attr / batch_spawn_along_path`）在**服务端**对选择集扇出为原子 tick 边界变更；不引入脚本即不新增 DSL，宏集合封闭、可枚举、可被 AI 生成器调用。
- 无脚本优先：UI 面板参数化；脚本（WorldPlugin）仅作为 L2/L3 逃生舱。

### D3 逻辑吸附 = 落点 bind 生成 Relation（SK 协议 + SA 交互）

- 吸附的两级语义：视觉对齐（纯前端）与**逻辑绑定**（吸附提交时 emit `bind(name="is_on", src=实体, dst=落点)`）。开启吸附模式与否决定提交时是否附带 bind——自由模式仍可放置但不建立逻辑归属。
- 落点是普通 Entity（point geometry + `#slot` tag 或按 parent 声明的合法域），不为棋盘/网格引入新本体。
- 实体 `kill` 时由命令层级联 `unbind` 其出入边（清偿 M1 的悬空边限制）。

### D4 Always-On = 默认运行态（Runner 语义微调）

- `ModelSession` 创建即处于 running（可配 `autostart=False` 保留现状）；编辑动作本就走命令队列、tick 边界生效，因此"编辑即运行"不需要新机制，只改默认值与 UI 文案。
- 时间线面板语义从"播放/暂停"扩展为"录制+分叉入口"，为 D1 铺路。

### D5 AI 边界（重申红线并给出口）

- SK 核心不 import LLM、API 领域无关（维持 ADR-001 §7）。
- 生成式交互的落位：**AI 助手是 SA/中游工具侧的 ModelCommand 生成器**（自然语言 → 命令流 → tick 边界执行 → 快照观察），与 D2 的封闭宏集合天然互为接口。

## 三、非目标

世界线的全局回滚/时间旅行调试器；批处理的图灵完备脚本；吸附的物理约束求解；AI 训练/RL 入核。

## 四、后果

- 协议影响：`is_on` 等关系边经 ADR-002 依赖 M1 关系投影（已实施于 v0.7.0）；D1/D2 均为增量命令与水合入口，不动 wire schema。
- 版本节奏：M1+M2 计入 SK v0.7.0；D1 的 fork/merge 与存档库计入 v0.8.0 议题。
- 文档义务：拍板后本 ADR 状态改 accepted，并同步《设计：场景工坊》§5.4/§12 与 API 手册命令表。
