### 第一个模型：捕食者-猎物

```python
import numpy as np
from world_model_kit import WorldModel, EntityKind

# 1. 定义 Agent 类型
prey = EntityKind("prey", position=True, velocity=True, energy=True, color=True)
predator = EntityKind("predator", position=True, velocity=True, energy=True, color=True)

# 2. 创建世界
model = WorldModel(world_width=200, world_height=200, backend="numpy")
model.register_kind(prey)
model.register_kind(predator)

# 3. 初始化 Agent
model.spawn("prey", n=500,
    x=np.random.uniform(0, 200, 500),
    y=np.random.uniform(0, 200, 500),
    energy=50.0, r=0, g=255, b=0,
)
model.spawn("predator", n=20,
    x=np.random.uniform(0, 200, 20),
    y=np.random.uniform(0, 200, 20),
    energy=100.0, r=255, g=0, b=0,
)

# 4. 定义行为
@model.step_for("prey")
def prey_step(m, ids):
    # 随机游走
    angle = np.random.uniform(0, 2 * np.pi, len(ids))
    m.move(ids, np.cos(angle) * 2, np.sin(angle) * 2)
    m.clamp_to_world(ids)

@model.step_for("predator")
def predator_step(m, ids):
    # 向最近的 prey 移动
    prey_pool = m.get_pool("prey")
    active_prey = m._lifecycle["prey"].active_indices
    if len(active_prey) == 0:
        return
    prey_x = prey_pool.d["x"][active_prey]
    prey_y = prey_pool.d["y"][active_prey]
    m.face_toward(ids, prey_x.mean(), prey_y.mean())
    m.move(ids, np.cos(m.d["heading"][ids]) * 3, np.sin(m.d["heading"][ids]) * 3)

# 5. 采集数据
model.collect("prey", fields=["energy"])
model.aggregate("prey", "count")

# 6. 运行
model.run(ticks=1000)

# 7. 导出
df = model.export_dataframe()
print(df.head())
```

## 核心概念

| 概念 | 说明 | 类比 |
|------|------|------|
| **WorldModel** | 世界容器，管理所有 Agent、空间、调度器 | NetLogo 的 `world` |
| **EntityKind** | Agent 类型描述符，声明该类型有哪些属性 | NetLogo 的 `breed` |
| **EntityPool** | SoA 列式存储，一个 kind 对应一个 pool | NumPy 结构化数组 |
| **step_for** | 每 tick 对指定 kind 执行的函数 | NetLogo 的 `ask turtles [ ... ]` |
| **tick** | 仿真时间的最小单位 | 离散时间步 |

## EntityKind：定义 Agent 类型

`EntityKind` 描述一种 Agent "长什么样"——它有哪些属性。不用的属性不占内存。

### 预置属性组

| 属性组 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `position=True` | `x, y` | float32 | 2D 位置 |
| `position_3d=True` | `x, y, z` | float32 | 3D 位置 |
| `velocity=True` | `vx, vy` | float32 | 速度向量 |
| `heading=True` | `heading` | float32 | 朝向角（弧度） |
| `speed=True` | `speed` | float32 | 速率 |
| `energy=True` | `energy` | float32 | 能量 |
| `age=True` | `age` | int32 | 存活 tick 数 |
| `color=True` | `r, g, b` | uint8 | 颜色 |
| `size=True` | `size` | float32 | 显示大小 |
| `team=True` | `team` | int32 | 阵营 ID |
| `group=True` | `group` | int32 | 子群组 ID |
| `state=True` | `state` | int32 | 状态机当前状态 |
| `state_timer=True` | `state_timer` | int32 | 当前状态持续 tick |

### 自定义字段

```python
trader = EntityKind("trader",
    position=True,
    energy=True,
    custom={
        "wealth": np.float32,
        "risk_tolerance": np.float32,
        "strategy": "U20",        # 最多 20 字符的字符串
    }
)
```

## Agent 生命周期

```
spawn() → PENDING → activate() → ACTIVE ↔ DORMANT → kill() → DEAD
```

| 方法 | 说明 |
|------|------|
| `model.spawn(kind, n, **attrs)` | 批量创建 Agent，返回索引数组 |
| `model.activate(ids)` | 激活（加入 step 循环） |
| `model.deactivate(ids)` | 停用（保留数据，跳过 step） |
| `model.kill(ids)` | 逻辑删除（标记不可用） |
| `model.get_pool(kind)` | 获取底层 EntityPool（L1 直通） |

## 空间操作

所有空间操作在 SoA 上批量执行——传入的 `ids` 是数组，操作为向量化。

### 移动

```python
model.move(ids, dx, dy)                        # 相对位移
model.move_to(ids, target_x, target_y)          # 绝对移动
model.move_toward(ids, target_x, target_y, max) # 朝向目标移动
```

### 边界处理

```python
model.clamp_to_world(ids)    # 钳制在世界边界内
model.wrap_toroidal(ids)     # 环形世界（穿墙从对面出现）
model.bounce(ids)            # 弹性反弹
```

### 查询

```python
dists = model.distance(a_ids, b_ids)            # 成对距离
matrix = model.distance_matrix(a_ids, b_ids)    # 全对距离矩阵 O(|A|×|B|)
nearest = model.nearest(ids, x, y, k=3)         # k 最近邻
nearby = model.within_radius(ids, x, y, r)       # 半径内搜索
```

### 旋转

```python
model.rotate(ids, angle)                        # 旋转朝向角
model.face_toward(ids, target_x, target_y)       # 朝向目标
```

## 调度系统

控制每个 tick 中 Agent 的执行顺序。

| 调度器 | 行为 | 默认？ |
|--------|------|--------|
| `RandomScheduler` | 每 tick 随机 shuffle | ✅ 默认 |
| `SequentialScheduler` | 按创建顺序 | |
| `ByKindScheduler` | 按 kind 分组执行 | |
| `ParallelScheduler` | 所有 Agent 同时 step | |
| `PhaseScheduler` | 阶段机模式 | |

```python
from world_model_kit.schedule import SequentialScheduler
model.set_scheduler("prey", SequentialScheduler())
```

## 内置行为

```python
# 随机游走
model.behaviors.random_walk("prey", step_size=1.0)

# Boids 群集
model.behaviors.flocking("bird",
    separation_weight=1.5,
    alignment_weight=1.0,
    cohesion_weight=1.0,
    perception_radius=5.0,
)

# 追捕-逃跑
model.behaviors.pursuit_evasion(
    pursuers="predator",
    evaders="prey",
    capture_radius=2.0,
)

    infection_radius=1.5,
    infection_prob=0.3,
    recovery_ticks=100,
)
```

```python
road = model.create_curve("highway", points=[(0,0), (100,50), (200,100)])
```

## 三层接入策略

用户可以在任意一层进入，按需下沉：

| 层级 | 代码量 | 适合场景 |
|------|--------|----------|
| **L3 DSL** | ~10 行 | 教学、快速原型、内置行为一键调用 |
| **L2 API** | ~50 行 | 日常工作、自定义 step 逻辑 |
| **L1 Raw** | ~200 行 | 极致性能优化、自定义数据结构 |

```python
# L3: 一行搞定
model.behaviors.flocking("bird")

# L2: 自定义 step
@model.step_for("bird")
def my_step(m, ids):
    m.move(ids, dx, dy)

# L1: 直接操作 EntityPool
pool = model.get_pool("bird")
pool.d["x"][active] += pool.d["vx"][active] * dt
```

## 常见问题

### Q: 如何切换 GPU 加速？

```python
model = WorldModel(backend="torch")  # PyTorch CUDA
model = WorldModel(backend="mlx")    # Apple Silicon
model = WorldModel(backend="jax")    # JAX GPU
```

### Q: 如何复现仿真结果？

```python
model = WorldModel(seed=42)
np.random.seed(42)  # 如果在 step 中使用 numpy random
```

### Q: 支持多少 Agent？

| 后端 | 推荐规模 |
|------|----------|
| NumPy | < 10⁵ |
| PyTorch CUDA | 10⁵ ~ 10⁷ |
| MLX (Apple Silicon) | < 10⁶ |

### Q: 如何对接前端可视化？

```python
viewmodel = model.export_viewmodel()  # 导出标准 JSON
# 前端使用 <WorldViewport2D :viewModel="viewmodel" />
```
