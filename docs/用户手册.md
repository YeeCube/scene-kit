## 快速开始

### 安装

```bash
pip install scene-kit
```

### 第一个模型：捕食者-猎物

```python
import numpy as np
from scene_kit import WorldModel, EntityKind

# 1. 创建世界（2D surface）
model = WorldModel(backend="numpy", seed=42)
model.add_root_surface(200, 200)

# 2. 定义 Entity 类型
prey = EntityKind("prey", geometry="point",
    tags={"energy": np.float32, "vx": np.float32, "vy": np.float32})
predator = EntityKind("predator", geometry="point",
    tags={"energy": np.float32, "vx": np.float32, "vy": np.float32})
model.register_kind(prey)
model.register_kind(predator)

# 3. 初始化 Entity
model.spawn("prey", n=500,
    u=np.random.uniform(0, 200, 500),
    v=np.random.uniform(0, 200, 500),
    energy=50.0, r=0, g=200, b=0)
model.spawn("predator", n=20,
    u=np.random.uniform(0, 200, 20),
    v=np.random.uniform(0, 200, 20),
    energy=100.0, r=220, g=30, b=30)

# 4. 定义行为
@model.step_for("prey")
def prey_step(m, ids):
    angle = np.random.uniform(0, 2*np.pi, len(ids))
    m.move("prey", ids, np.column_stack([np.cos(angle)*1.5, np.sin(angle)*1.5]))
    m.clamp_to_world("prey", ids)

@model.step_for("predator")
def predator_step(m, ids):
    prey_active = m._lifecycle["prey"].active_indices
    if len(prey_active) == 0: return
    pu = m.attr("prey", "u")[prey_active]; pv = m.attr("prey", "v")[prey_active]
    m.move_toward("predator", ids, float(pu.mean()), float(pv.mean()), max_distance=2.5)
    m.clamp_to_world("predator", ids)

# 5. 采集数据
model.collector.collect("prey", ["energy"])
model.collector.aggregate("prey", "energy", ["mean", "count"])

# 6. 运行
model.run(ticks=200)

# 7. 查看结果
print(f"survived: prey={model._lifecycle['prey'].active_count}")
df = model.collector.export_dataframe()
print(df.tail())
```

### 对比 v0.1.0

| v0.1.0 (已废弃) | v0.2.0 |
|---|---|
| `WorldModel(world_width=200, world_height=200)` | `WorldModel()` + `add_root_surface(200, 200)` |
| `EntityKind("prey", position=True, velocity=True, energy=True)` | `EntityKind("prey", geometry="point", tags={"vx": np.float32, "vy": np.float32, "energy": np.float32})` |
| `spawn(x=..., y=...)` | `spawn(u=..., v=...)` |
| `attr("prey", "x")` | `attr("prey", "u")` |
| `move("prey", ids, dx, dy)` | `move("prey", ids, np.column_stack([du, dv]))` |

v0.3.0 的前端协议不再把实体编码为 `agents` 对象数组。正式协议以 RECS 风格 SoA 表达 Entity；`Agent` 只是某些模型中的语义角色，不能作为通用顶层数据结构。

## 核心概念

| 概念 | 说明 |
|---|---|
| **WorldModel** | 世界容器，管理所有 Entity、geometry、调度器、采集器 |
| **EntityKind** | Entity 类型描述符：geometry + tags + parent + type |
| **geometry** | 几何形态。六选一：`point` / `surface` / `volume` / `path` / `segment` / `hypergraph` |
| **tags** | 领域属性字典。`{"energy": np.float32}` 展开为 EntityPool 列 |
| **parent** | 父 entity 的 kind。将 entity 挂载到另一个 entity 上 |
| **step_for** | 每 tick 对指定 kind 执行的函数 |
| **root surface/volume** | 世界的根几何空间。通过 `add_root_surface()` 或 `add_root_volume()` 设置 |

## 创建世界

```python
model = WorldModel(
    backend="numpy",    # 计算后端: numpy / torch / mlx / jax
    seed=42,            # 随机种子（可复现）
)

# 2D 世界（最常用）
model.add_root_surface(200, 200,
    boundary_u="clamp",    # U 方向边界: clamp / toroidal / bounce
    boundary_v="clamp",    # V 方向边界:
)

# 3D 世界
model.add_root_volume(100, 100, 100)
```

> **为什么不是 `WorldModel(width, height)`？** SceneKit 的世界是 Entity 嵌套树，没有单一的"尺寸"。`add_root_surface` 只是为根 entity 设置一个 2D surface geometry。如果你的世界不需要边界（如纯图网络），甚至可以不调用它。

## EntityKind：定义 Entity 类型

### 核心字段

```python
EntityKind(
    name="prey",              # 类型名（必须）
    geometry="point",         # 几何形态（必须）
    dim=0.0,                  # 内在维度（0=自动推断）
    parent=None,              # 父 kind 名称，None=挂载到根
    tags={                    # 领域属性字典
        "energy": np.float32,
        "vx": np.float32,
        "vy": np.float32,
        "team": np.int32,
    },
    type="AGENT",             # AGENT / ENTITY / OBJECT / ENV
    perceive=None,            # 可选感知声明（见Perception章节）
)
```

### geometry 六种类型

| geometry | 说明 | 位置列 | children 自由度 |
|---|---|---|---|
| `point` | 0 维质点 | `u, v` | 无 children |
| `surface` | 2D 连续面 | `u, v` | 2 DOF |
| `volume` | 3D 连续体 | `u, v, w` | 3 DOF |
| `path` | 1D 折线网络 | `t` | 1 DOF（沿边步进） |
| `segment` | 1D 线段 | `t` | 1 DOF |
| `hypergraph` | 离散超图 | `vertex_id` | 离散步进 |

> **当前实现**: `point` / `surface` / `volume`。`path` / `segment` / `hypergraph` 属于后续版本规划。

### 系统预设列（所有 kind 自动包含）

| 列名 | dtype | 说明 |
|---|---|---|
| `u, v` (或 `u, v, w`) | float32 | 参数坐标（geometry 决定） |
| `mass` | float32 | 质量 |
| `r, g, b, a` | uint8 | 颜色 + 透明度 |
| `label` | U32 | 显示标签 |
| `_parent_id` | int64 | 父 entity 索引（-1=根） |
| `_type` | U16 | AGENT / ENTITY / OBJECT / ENV |
| `_state` | int32 | FSM 当前状态 |
| `_state_timer` | int32 | 状态持续 tick |

## Entity 生命周期

```
spawn() → PENDING → activate() → ACTIVE ↔ deactivate() → DORMANT
                                    ↓
                                kill() → DEAD
```

spawn 后**自动激活**。

```python
ids = model.spawn("prey", n=100, u=..., v=..., energy=50.0)
model.deactivate("prey", ids[:10])   # 暂时停用
model.activate("prey", ids[:10])     # 恢复
model.kill("prey", ids[50:55])       # 永久删除
```

### L1 直通

```python
pool = model.get_pool("prey")           # → RECS EntityPool
raw = pool.d["energy"]                  # → 裸 NumPy 数组
```

## 空间操作

### 移动

```python
# 向量化移动。delta.shape = (n, parent_dim)
model.move("prey", ids, np.column_stack([du, dv]))

# 绝对移动
model.move_to("prey", ids, target_u_arr, target_v_arr)

# 朝向目标
model.move_toward("prey", ids, target_u, target_v, max_distance=2.5)
```

### 边界处理

```python
model.clamp_to_world("prey", ids)    # 钳制到根 surface 边界
model.wrap_toroidal("prey", ids)     # 环形环绕
```

### 查询

```python
# 成对距离
dists = model.distance("prey", a_ids, b_ids)

# 半径搜索
nearby = model.within_radius("prey", ids, cx=100, cy=100, radius=30.0)

# 世界坐标递归求解
world_pos = model.resolve_world_position("prey", ids)  # → (n, 3)
```

### 嵌入与交互

```python
# 挂载到另一个 entity
model.embed_to("vehicle", ids, "road", parent_ids)
# 脱离
model.detach("vehicle", ids)
# 切换宿主
model.reattach("vehicle", ids, "new_road", new_parent_ids)

# 相交检测
model.intersects("vehicle", vid, "obstacle", oid)
pairs = model.intersecting_pairs("vehicle", "obstacle")
```

## Tag 系统与跨 kind 查询

tags 是 SceneKit 的领域属性系统。不预设 `energy` 或 `hp`——一切由用户声明。

```python
# 定义
prey = EntityKind("prey", geometry="point",
    tags={"energy": np.float32, "edible": np.bool_})
predator = EntityKind("predator", geometry="point",
    tags={"energy": np.float32})

# 跨 kind 查询
model.tagged("energy")
# → {"prey": array([...]), "predator": array([...])}

model.kinds_with_tag("edible")
# → ["prey"]

model.kinds_with_tag("energy")
# → ["predator", "prey"]

# 按值过滤
low_energy = model.where("prey", "energy", lt=30.0)
# → array([3, 7, 12, ...])

# 跨 kind 空间查询
nearby_food = model.within_radius(
    "predator", predator_ids,
    target_kinds=model.kinds_with_tag("edible"),
    radius=50.0)
```

## Perception 感知框架

声明 `perceive` 字段，step 函数自动接收结构化的 `Perception` 对象。

```python
smart_prey = EntityKind("smart_prey", geometry="point",
    tags={"energy": np.float32, "vx": np.float32, "vy": np.float32},
    perceive={
        "radius": 30.0,
        "of_kinds": ["predator", "food"],
        "self_tags": ["energy"],
    })

@model.step_for("smart_prey")
def smart_prey_step(m, perception):
    """perception 是 Perception 对象，不是 ids 数组。"""
    energy = perception.self_tags["energy"]
    nearby_predators = perception.neighbors["predator"]
    nearby_food = perception.neighbors["food"]

    # 感知驱动决策...
```

### perceive 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `radius` | float | 空间感知半径。0=关闭 |
| `of_kinds` | list[str] | 关注哪些 kind |
| `self_tags` | list[str] \| None | 需要注入的自身 tags。None=全部 |
| `fields` | list[str] | 关注的场名（远期） |
| `collision_radius` | float | 碰撞检测半径 |

> **未声明 perceive** 的 kind，step 函数仍收 `ids` 数组——完全向后兼容。

## 调度系统

```python
from scene_kit.schedule import (
    SequentialScheduler,   # 创建顺序（默认）
    RandomScheduler,       # 每 tick 随机 shuffle
    ByKindScheduler,       # kind 分组内 shuffle
    PhaseScheduler,        # 阶段机（回合制）
)

model = WorldModel(scheduler=RandomScheduler(seed=42))
```

| 调度器 | 行为 | 场景 |
|---|---|---|
| `SequentialScheduler` | 按注册顺序 | 确定性仿真 |
| `RandomScheduler` | 每 tick shuffle | 生态仿真 |
| `ByKindScheduler` | 分组内 shuffle | 多物种 |
| `PhaseScheduler` | 阶段机 | 回合制、游戏 |

## 内置行为

通过 `model.behaviors` 访问。每个方法自动注册 `@step_for`。

```python
# 随机游走
model.behaviors.random_walk("prey", step_size=1.0)

# Boids 群集
model.behaviors.flocking("bird",
    separation=1.5, alignment=1.0, cohesion=1.0,
    radius=5.0, max_speed=2.0)

# 追捕-逃跑
model.behaviors.pursuit_evasion(
    pursuer_kind="predator", evader_kind="prey",
    capture_radius=2.0, pursuit_speed=1.5)
```

## Plugin 扩展系统

将一组 EntityKind + step 函数 + 采集器 + 资源封装为一个可复用模块。

```python
from scene_kit import WorldPlugin

class MyFlockingPlugin(WorldPlugin):
    name = "my_flocking"

    def register_kinds(self, world):
        world.register_kind(EntityKind("bird", geometry="point",
            tags={"vx": np.float32, "vy": np.float32}))

    def register_behaviors(self, world):
        world.behaviors.flocking("bird", separation=1.5)

    def register_resources(self, world):
        world.add_resource({"world_size": 200, "num_birds": 100})

# 使用
model = WorldModel()
model.add_root_surface(200, 200)
model.add_plugin(MyFlockingPlugin())

cfg = model.get_resource(dict)  # → {"world_size": 200, ...}
model.spawn("bird", n=cfg["num_birds"], u=..., v=...)
```

## WorldSnapshot 与交互式前端

正式快照固定为 RECS 风格 SoA。每个 `EntityKind` 对应一个 `EntityBatch`，`columns` 的每个键都是长度等于 `count` 的列；`uid` 是稳定 Entity UID，使用十进制字符串承载 RECS 的 int64。

```python
from scene_kit import SnapshotProjection

projection = SnapshotProjection(
    kinds=("prey", "predator"),
    columns={"prey": ("u", "v", "energy", "r", "g", "b", "a")},
    viewport={"u_min": 0, "u_max": 100, "v_min": 0, "v_max": 100},
    include_metrics=True,
    include_world_coordinates=False,
)
snapshot = model.export_snapshot(projection, format="dict")
```

快照顶层字段为 `protocol`、`protocolVersion`、`snapshotId`、`tick`、`time`、`world`、`entityBatches`、`relationBatches` 和 `metrics`。当前实现的关系批次保留协议位置，具体关系导出仍是后续能力；不要把空关系批次误解为没有关系模型。

不要依据实体数量切换对象数组和数组行：固定列名和固定 batch schema 才能让 Vue 选择器、增量更新和大规模渲染保持一致。`WorldDelta` 按 `(kind, uid)` 表达新增、删除和变更列。

### 运行会话

`ModelSession` 在 `WorldModel` 外提供 tick 边界和可序列化命令：`play`、`pause`、`step`、`reset`、`set_rate`、`set_parameter`、`spawn`、`despawn`、`move`、`set_tag`。WebSocket 服务发送 `hello`、`snapshot`/`delta`、`commandResult`、`error` envelope。

```bash
uv run --extra server python -m demos.demo_flocking --serve
```

前端 SDK 的职责分层如下：`@scene-kit/core` 负责协议校验、选择器、delta 应用和 bridge；`@scene-kit/vue` 提供组合式 API；`@scene-kit/renderer-2d` 负责 Canvas 2D 呈现；`@scene-kit/main-ui-adapter` 只在需要接入 `main-ui` 时使用；Scene Studio 是这些包的消费者示例。

### 兼容 ViewModel

`model.export_viewmodel()` 仅用于旧代码迁移、调试或临时打印。它返回 AoS 的 `agents` 列表，不能代表 SceneKit 的 Entity 本体，也不应作为新的跨进程协议。

## 常见问题

**Q: 如何切换到 GPU？**
```python
model = WorldModel(backend="torch")
```
所有数组在 PyTorch Tensor 上，无需手写 `.cuda()`。还支持 `mlx` (Apple Silicon) 和 `jax`。

**Q: 如何创建 3D 世界？**
```python
model = WorldModel()
model.add_root_volume(100, 100, 100)
particle = EntityKind("particle", geometry="volume",
    tags={"vx": np.float32, "vy": np.float32, "vz": np.float32})
```

**Q: 如何让 entity 成为另一个 entity 的 "空间"？**
```python
road = EntityKind("road", geometry="surface", dim=2.0)
vehicle = EntityKind("vehicle", geometry="point", parent="road")
```
或者在 spawn 后动态挂载：`model.embed_to("vehicle", ids, "road", parent_ids)`。

**Q: 运行结果怎么给前端渲染？**
使用 `export_snapshot()` 或 `ModelSession`/WebSocket；前端用 `@scene-kit/core` 与 `@scene-kit/vue` 接收固定 SoA 快照。
