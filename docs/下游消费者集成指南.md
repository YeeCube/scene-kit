# SceneKit 下游消费者集成指南（Scene Suite 伞形品牌）

> **版本**: 0.6.0 | **最后更新**: 2026-08-14

## Studio/前端接入（v0.6）

浏览器端使用 `WebSocketBridge` 和 `WorldModelProvider` 消费快照，收到增量时会自动合并，断线后采用退避策略重连：

```ts
const bridge = new WebSocketBridge('ws://127.0.0.1:8765');
// <WorldModelProvider :bridge="bridge">...</WorldModelProvider>
```

`@scene-kit/vue` 的 `commands` 提供 `spawn`、`despawn`、`move`、`setAttribute` 和 `setTag`。所有包可通过 `file:../scene-kit/frontend/packages/*` 本地依赖；不要将内部 `workspace:*` 依赖复制到下游应用。

这份指南面向使用 SceneKit 构建自己应用的团队。它只描述公开的包、协议和集成边界，不包含任何特定项目配置。

## 选择集成层级

| 需求 | 推荐包 |
|---|---|
| 只接收快照并自行渲染 | `@scene-kit/core` |
| 在 Vue 组件中订阅 Entity 和指标 | `@scene-kit/core` + `@scene-kit/vue` |
| 需要 2D Canvas 呈现 | 再加入 `@scene-kit/renderer-2d` |
| 接入消费者自己的 main-ui 工作台 | 最后加入 `@scene-kit/main-ui-adapter` |
| 直接使用完整参考界面 | 运行 `frontend/apps/studio`，再按需替换编辑器 |

SceneKit 的前端包不是必须整体嵌套的 App。下游可以只使用核心协议和 Vue 组合式 API，自己决定布局、状态面板、路由和 UI 组件；也可以把 Studio 当作可运行的参考应用。两种方式共享同一 `WorldSnapshot` 契约。

## Python 服务端

```python
from scene_kit import ModelSession
from scene_kit.transport import WebSocketModelServer

model = make_model({"seed": 42})
session = ModelSession(model, model_factory=make_model, parameters={"seed": 42})
```

安装可选服务依赖后，在应用生命周期中启动 `WebSocketModelServer(session)`。服务端只传递协议 envelope；相机、选中项和面板折叠等纯界面状态应留在客户端。

## 前端客户端

```ts
import {WebSocketBridge} from '@scene-kit/core';
import {WorldModelProvider} from '@scene-kit/vue';

const bridge = new WebSocketBridge('ws://127.0.0.1:8765');
```

将 bridge 交给 `WorldModelProvider` 后，使用 `useWorldModel()`、`useEntityBatch(kind)`、`useEntity(ref)` 和 `useMetrics()` 读取状态。选择实体时保存 `{kind, uid}`，不要保存 batch 行号。

## 协议约束

- `WorldSnapshot` 的 `entityBatches` 按 kind 分组，所有公开字段都是等长列。
- `uid` 始终存在，编码为十进制字符串，以避免 JavaScript number 丢失 int64 精度。
- 不因实体数量改变对象/数组结构；列 schema、字段名和 envelope 类型保持稳定。
- `WorldDelta` 依赖上一份 `snapshotId`；客户端发现基准不匹配或应用失败时，应重新请求完整快照。
- `relationBatches` 是正式协议的一部分；当前 Python 导出器尚未填充关系数据，下游不应据此假定模型没有关系。

## main-ui 集成

`main-ui` 只在 `@scene-kit/main-ui-adapter` 和应用层出现。适配器把 SceneKit Studio editor 注册到消费者拥有的 runtime；它不会改变 core/Vue 的数据模型，也不会要求下游必须采用 SceneKit 的整套界面。若消费者已有自己的工作台，直接使用 core/Vue/renderer 即可。
