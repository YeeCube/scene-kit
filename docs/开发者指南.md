## 项目概述

world-model-kit 是基于 RECS（SoA ECS 引擎）的**世界建模工具包**。核心本体只有三个原语：

$$
\mathcal{W} = (\mathcal{E}, \mathcal{R}, \mathcal{T})
$$

即 Entity（行）、Relation（关系）、Tag（语义标签）。"空间"只是 Entity 之间 `parent` 关系的人类可读标签。

### 四层接入

```
L0 Expression:  model.behaviors.flocking("bird")
L1 Raw:         pool = model.get_pool("prey")
L2 API:         WorldModel + EntityKind + step_for
L3 Plugin:      model.add_plugin(MyPlugin())
```

## 架构概览

### 数据流

```
用户代码 (@step_for)
  ↓ 调用 L2 API (move, distance, spawn, kill...)
WorldModel (Facade)
  ↓ 翻译为 RECS 操作 + Geometry 分发
EntityPoolBridge
  ↓
EntityPool (SoA) / Backend (NumPy / PyTorch / MLX / JAX)
```

### 模块依赖图

```
entity_kind.py               ← 纯数据类，无依赖
entity_pool_bridge.py        ← 依赖 entity_kind + RECS
entity_lifecycle.py          ← 依赖 entity_pool_bridge
perception.py                ← 纯数据类
   ↓
geometry/{base,point,surface,volume}.py  ← 独立，无 WMK 依赖
schedule/schedulers.py       ← 独立
behaviors/{registry,*.py}    ← 依赖 world.py（注入 step_for）
collect/collector.py          ← 独立
viewmodel/export.py           ← 依赖 world.py
plugins/base.py               ← 独立
embedding/operations.py       ← 依赖 world.py
   ↓
world.py                     ← Facade，聚合以上全部
__init__.py                  ← 公开导出
```

### 关键设计决策

| 决策 | 理由 |
|---|---|
| EntityKind 不持数据 | 数据在 EntityPool 中，Kind 是 dtype 模板 |
| 一 kind 一 pool | 列结构不同，分开存储最高效 |
| `world_width`/`world_height` 移除 | 世界是 Entity 嵌套树，无单一尺寸 |
| `add_root_surface()` 显式声明 | 用户明确知道自己创建了什么几何 |
| `tags` 替代布尔开关 + `custom` | 一个字典替代 15 个布尔字段 + 独立 custom，更统一 |
| geometry 决定位置列 | `point`→`u,v`；`volume`→`u,v,w`；统一接口 |
| `move(delta)` 替代 `move(dx,dy)` | 维度无上限，由 parent 的 geometry 决定 |
| 不保留 deprecated 兼容层 | 清爽代码，不积累屎山 |
| L3 全用 L2 实现 | L3 只是 L2 的 5-10 行组合 |

## 核心模块详解

### `entity_kind.py`

`EntityKind` 是 `@dataclass` 纯数据描述符。核心方法是 `_kind_to_dtypes()`。

**geometry → 位置列映射**：
```python
_GEOMETRY_POSITION_COLS = {
    "point": [("u", np.float32), ("v", np.float32)],
    "surface": [("u", np.float32), ("v", np.float32)],
    "volume": [("u", np.float32), ("v", np.float32), ("w", np.float32)],
    "path": [("t", np.float32)],
    "segment": [("t", np.float32)],
    "hypergraph": [("vertex_id", np.int64)],
}
```

**`_kind_to_dtypes()` 展开顺序**：
1. 系统保留列（`_kind`, `_active`, `_step_fn`, `_parent_id`, `_type`, `_state`, `_state_timer`）
2. 无条件预设列（`mass`, `r/g/b/a`, `label`）
3. geometry → 位置列
4. tags → 展开为列

### `world.py`

`WorldModel` 是用户唯一的入口。它聚合了：
- `_bridge: EntityPoolBridge` — 管理所有 pool
- `_lifecycle: dict[str, EntityLifecycleManager]` — 每个 kind 的状态机
- `_kind_defs: dict[str, EntityKind]` — 每个 kind 的定义（geometry、tags、perceive）
- `_tag_index: dict[str, set[str]]` — tag → kind 倒排索引
- `_geometry: dict[str, Geometry]` — 每个 kind 的几何实例
- `_root_geometry: Geometry | None` — 根几何
- `_scheduler: SchedulerBase` — 调度器
- `_resources: dict[type, Any]` — 全局资源

**`step()` 执行流程**：
1. scheduler 排序 kind 和 entity
2. 对声明了 `perceive` 的 kind，填充 `Perception`
3. 调用 `@step_for` 函数
4. 触发 DataCollector

### `geometry/`

每种 geometry 实现 5 个接口：
- `metric(p, q)` — 距离
- `move(positions, delta, dt)` — 移动
- `neighborhood(positions, query, radius)` — 邻域
- `contains(positions)` — 包含判定
- `param_to_local(positions)` — 参数→笛卡尔

**首期实现**：`PointGeometry` / `SurfaceGeometry` / `VolumeGeometry`。

**`SurfaceGeometry`** 特殊支持三种边界模式：`clamp` / `toroidal` / `bounce`。

### `behaviors/`

每个行为是独立模块。`BehaviorRegistry` 统一入口（通过 `model.behaviors` 访问）。每个方法内部用 `@step_for` 注册。

### `viewmodel/export.py`

`export_viewmodel()` 遍历所有 kind 的活跃 entity，读取位置+颜色，序列化为 JSON/dict。支持 `viewport` 参数进行视口裁剪。

## 扩展 WMK

### 新增 geometry

```python
from world_model_kit.geometry import Geometry

class MyGeometry(Geometry):
    dim = 2.0
    def metric(self, p, q): ...
    def move(self, positions, delta, dt=1.0): ...
    def neighborhood(self, positions, query, radius): ...
    def contains(self, positions): ...
    def param_to_local(self, positions): ...
```

> **当前限制**：geometry 在 `register_kind()` 时自动分配，尚无 `register_geometry()` 注册 API。自定义 geometry 的完整接入在 v0.3.0。

### 新增调度器

```python
from world_model_kit.schedule import SchedulerBase

class MyScheduler(SchedulerBase):
    def get_step_order(self, model): ...
    def get_active_order(self, model, kind, active_ids): ...
```

### 新增 Plugin

```python
from world_model_kit import WorldPlugin

class MyPlugin(WorldPlugin):
    name = "my"
    def register_kinds(self, world): ...
    def register_behaviors(self, world): ...
    def register_collectors(self, world): ...
    def register_resources(self, world): ...
```

### 新增内置行为

```python
# behaviors/my_behavior.py
def my_behavior(model, kind, **params):
    @model.step_for(kind)
    def step(m, ids):
        # 向量化操作...

# behaviors/registry.py
class BehaviorRegistry:
    def my_behavior(self, kind, **params):
        from world_model_kit.behaviors.my_behavior import my_behavior
```

## 编码规范

| 类型 | 约定 | 示例 |
|---|---|---|
| 模块 | `snake_case` | `entity_lifecycle.py` |
| 类 | `PascalCase` | `WorldModel`, `EntityKind` |
| 函数/方法 | `snake_case` | `register_kind()`, `resolve_world_position()` |
| 私有成员 | `_prefix` | `_bridge`, `_tag_index` |
| 常量 | `UPPER_SNAKE` | `DEFAULT_CAPACITY` |

### 类型注解

```python
# ✅ 正确
def spawn(self, kind: str, n: int = 1, **attrs: object) -> np.ndarray: ...

# ❌ 错误
def spawn(self, kind, n=1, **attrs): ...
```
