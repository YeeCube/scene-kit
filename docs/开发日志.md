## 2026-08-08 · v0.3.0 SoA 协议与交互式前端

### 变更类型: feat / docs

**变更内容**：

1. 新增 RECS 风格固定 schema 的 `WorldSnapshot`、`WorldDelta`、`EntityBatch` 和 `RelationBatch` 类型；快照始终使用 SoA 列，不再按实体数量切换 AoS/数组行结构。
2. 新增 `SnapshotProjection`，支持 kind、列、视口、指标和世界坐标投影；RECS int64 UID 以十进制字符串跨 JSON/TypeScript 传输。
3. 新增 `ModelSession` 命令边界和可选 `WebSocketModelServer`，支持 Studio 的 hello、snapshot、delta、commandResult、error 消息。
4. 新增 frontend PNPM workspace：`core`、`vue`、2D renderer、`main-ui` adapter 和 Studio；下游可以按层级消费，不要求使用完整 Studio。
5. 七个 demos 改为可导入的 `create_model(config)`，同时支持无前端 CLI 和 `--serve` 交互模式。
6. 更新 README、用户手册、API 手册、开发者指南，并新增脱敏的下游消费者集成指南。

**已知限制**：

- 当前版本只有 2D renderer；3D renderer、path/segment/hypergraph 的专用渲染器仍在后续计划中。
- `relationBatches` 已纳入协议，但 Python 快照导出尚未提供完整关系数据投影。
- WebSocket 服务适合本地/开发集成，鉴权、压缩、断线重连策略由部署应用负责。
- 尚未发布独立的 npm/PyPI release artifact；当前 frontend 包通过 workspace 构建。

## 2026-07-23 · v0.2.0 架构改造

### 里程碑：geometry 驱动的嵌套 Entity 树 + tags + parent 坐标链

**从**：v0.1.0 MVP（扁平 2D (x,y) 世界）
**到**：v0.2.0（geometry + parent + tags 体系）

**核心变更**：

1. **EntityKind 重设计**：从布尔开关模式升级为 `geometry`/`dim`/`parent`/`tags`/`type`/`perceive` 六字段
2. **Geometry 体系**：`Geometry` ABC + `PointGeometry`/`SurfaceGeometry`/`VolumeGeometry` 实现 + `resolve_world_position()` 递归坐标链
3. **嵌入与交互**：`embed_to`/`detach`/`reattach` + `intersects` + 三种边界模式（clamp/toroidal/bounce）
4. **Tag 系统**：`tagged()`/`kinds_with_tag()`/`where()` 跨 kind 查询
5. **Perception 感知框架**：`Perception` 数据结构 + `step()` 中的 `_prepare_perception()` 自动填充
6. **模块提取**：从 `world.py` 拆分出 `geometry/` `schedule/` `collect/` `behaviors/` `viewmodel/` `embedding/` `plugins/` 共 7 个子模块
7. **Plugin + Behavior 系统**：`WorldPlugin` 基类 + `BehaviorRegistry`（flocking/pursuit_evasion/random_walk）
8. **调度器**：`SchedulerBase` + `SequentialScheduler`/`RandomScheduler`/`ByKindScheduler`/`PhaseScheduler`
9. **数据采集与 ViewModel 导出**：`DataCollector` + `export_viewmodel()` + `export_dataframe()`
10. **7 个示例脚本**：覆盖经典模型（捕食者-猎物、交通流、群体行为、曲线追踪等）和 SceneKit 特性展示（Plugin 封装、Perception 感知）
11. **39 个综合测试**：覆盖 EntityKind、Geometry、WorldModel、Tag、Plugin、DataCollector、ViewModel、Scheduler

**新增文件** (17 个模块文件)：
```

embedding/{__init__,operations}.py
schedule/{__init__,schedulers}.py

```

**暂缓到 v0.3.0+**：

- 场系统（scalar/vector field）
