## 2026-07-23 · v0.2.0 架构改造

### 里程碑：geometry 驱动的嵌套 Entity 树 + tags + parent 坐标链

**从**：v0.1.0 MVP（扁平 2D (x,y) 世界）
**到**：v0.2.0（geometry + parent + tags 体系）

**核心变更**：

1. **EntityKind 重设计**：从布尔开关模式升级为 `geometry`/`dim`/`parent`/`tags`/`type`/`perceive` 六字段
2. **Geometry 体系**：`Geometry` ABC + `PointGeometry`/`SurfaceGeometry`/`VolumeGeometry` 实现 + `resolve_world_position()` 递归坐标链
3. **嵌入与交互**：`embed_to`/`detach`/`reattach` + `intersects` + 三种边界模式（clamp/toroidal/bounce）
4. **Tag 系统**：`tagged()`/`kinds_with_tag()`/`where()` 跨 kind 查询
5. **Perception 感知框架**：`Perception` 数据结构 + `step()` 中的 `_prepare_perception()` 自动填充
6. **模块提取**：从 `world.py` 拆分出 `geometry/` `schedule/` `collect/` `behaviors/` `viewmodel/` `embedding/` `plugins/` 共 7 个子模块
7. **Plugin + Behavior 系统**：`WorldPlugin` 基类 + `BehaviorRegistry`（flocking/pursuit_evasion/random_walk）
8. **调度器**：`SchedulerBase` + `SequentialScheduler`/`RandomScheduler`/`ByKindScheduler`/`PhaseScheduler`
9. **数据采集与 ViewModel 导出**：`DataCollector` + `export_viewmodel()` + `export_dataframe()`
10. **7 个示例脚本**：覆盖经典模型（捕食者-猎物、交通流、群体行为、曲线追踪等）和 WMK 特性展示（Plugin 封装、Perception 感知）
11. **39 个综合测试**：覆盖 EntityKind、Geometry、WorldModel、Tag、Plugin、DataCollector、ViewModel、Scheduler

**新增文件** (17 个模块文件)：
```
geometry/{__init__,base,point,surface,volume}.py
embedding/{__init__,operations}.py
schedule/{__init__,schedulers}.py
collect/{__init__,collector}.py
behaviors/{__init__,registry,flocking,pursuit_evasion,random_walk}.py
viewmodel/{__init__,export}.py
plugins/{__init__,base}.py
perception.py
tests/test_core.py
```

**暂缓到 v0.3.0+**：
- `segment`/`path`/`hypergraph` geometry 实现
- 场系统（scalar/vector field）
- 事件系统（EventBus）
- 分形/统计流形 geometry
- 前端 `@world-model-kit/core` + `@world-model-kit/vue`

## 2026-07-15 · 项目初始化 + MVP 核心模块

### 里程碑：仓库创建、设计定稿、核心 MVP 跑通

**产出**:
- 仓库 `world-model-kit` 创建于 `/Users/ethan/CoreFiles/ProjectsFile/world-model-kit`
- 设计文档定稿（15 章完整设计，含 Python 后端架构和前端 TS+Vue3 架构）
- 文档骨架：用户手册、开发者指南、开发日志、API 手册
- MVP 核心四模块实现并验证通过：
  - `entity_kind.py` — EntityKind 描述符 + `_kind_to_dtypes()` 展开逻辑
  - `entity_pool_bridge.py` — RECS EntityPool 桥接层
  - `entity_lifecycle.py` — 生命周期状态机（ACTIVE/DORMANT/DEAD）
  - `world.py` — WorldModel 核心（注册/spawn/step/run/空间操作）
- Demo `demos/demo_predator_prey.py` 跑通：500 prey + 20 predator, 200 ticks
- 开发计划存放在 Obsidian tasks 目录

**技术决策**:
- Python >= 3.13，依赖 NumPy >= 1.24 + RECS（通过 .pth 文件桥接，待 RECS 修复 pip 安装）
- 所有空间操作向量化（SoA 批量执行）
- `step_for` 装饰器模式注册 step 函数
- spawn 后默认激活（用户可显式 deactivate 延迟）

**已知问题**:
- ~~RECS `pyproject.toml` 缺少 `[build-system]` 和 `packages`，无法通过 pip 安装~~ ✅ 已修复
- 修复方式：在 RECS 的 `pyproject.toml` 中添加了 `[build-system]` 和 `[tool.setuptools.packages.find]`
- 现可通过 `uv pip install -e ../relation-entity-component-system --no-build-isolation` 安装
- 注意：world-model-kit 的 venv 需要用 `uv pip install setuptools` 确保 setuptools 可用
